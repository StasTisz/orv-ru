## 💡 Что это за проект?

`orv-ru` — это веб-читалка, статический генератор сайтов (SSG), сборщик электронных книг EPUB 3 и конвейер контроля качества перевода культовой корейской веб-новеллы **«Точка зрения всеведущего читателя»** (*Omniscient Reader's Viewpoint, ORV*, авторы Sing Shong) на русский язык.

На платформе реализованы **3 раздела (истории)**:
1. **Основная история** (главы 1–551) — канонический сюжет о Ким Докче и сценариях Звёздного Потока.
2. **Побочная история / Сиквел** (главы 553+) — продолжение новеллы о Ли Хакхёне и читателях в новой мировой линии.
3. **Ваншоты и бонусные главы** — спецвыпуски, дополняющие вселенную произведения.

Сайт функционирует как **прогрессивное веб-приложение (PWA)**: он мгновенно открывается в браузере на компьютерах и смартфонах, работает без интернета и не требует серверных баз данных.

## 🎯 Зачем это создано?

Любительские переводы длинных восточноазиатских новелл регулярно сталкиваются с тремя фундаментальными проблемами:
1. **Терминологический рассинхрон:** В текстах объемом более 1000 глав разные переводчики и языковые модели часто называют одних и тех же персонажей, созвездия, монстров и навыки десятками несовместимых вариантов.
2. **Потеря авторской верстки:** В ORV оформление текста имеет критическое сюжетное значение: синие голографические системные окна, канонические скобки цитирования созвездий `「...」`, полупрозрачные уведомления и сообщения Внешних Богов. В обычных «читалках» эта типографика превращается в неразборчивый плоский текст.
3. **Неудобные платформы с рекламой:** Большинство площадок перегружены навязчивыми баннерами, медленно работают на мобильных устройствах, теряют прогресс чтения и не открываются без стабильного подключения к сети.

**Задача `orv-ru`** — дать бескомпромиссную, чистую читалку: без рекламы, с безупречной канонической версткой, строгим словарным контролем терминологии и возможностью комфортного чтения как онлайн, так и в офлайн-режиме.

## 📖 Возможности читалки

* 🌐 **Чтение в браузере:** [**https://orv-ru.pages.dev/**](https://orv-ru.pages.dev/) — адаптивный интерфейс для мобильных устройств, планшетов и десктопа.
* 🎨 **13 цветовых тем:** От светлых и мягкой сепии до глубоких ночных (включая **OLED Midnight** с настоящим черным фоном для экономии заряда аккумулятора).
* 🔤 **Персонализация текста:** Выбор гарнитуры шрифта, регулировка размера текста, межстрочного интервала и ширины полосы чтения.
* 📑 **Живой поиск и навигация:** Мгновенная фильтрация глав по номеру и названию, удобное переключение стрелками на клавиатуре (`←` / `→`) и экранными кнопками.
* 💾 **Умное автосохранение:** Сохранение прочитанных глав и точной позиции скролла. При возвращении на сайт вы сразу продолжаете с того абзаца, где остановились.
* 📱 **Чтение без интернета (PWA):** Сайт можно установить на телефон или компьютер как самостоятельное приложение в один клик. Открытые главы сохраняются в кэше и доступны офлайн.
* 📚 **Экспорт в EPUB 3:** Каждую историю можно скачать в виде книги `.epub` со встроенными стилями системных окон и концевыми сносками для чтения в электронных ридерах (Apple Books, Moon+ Reader, PocketBook и др.).
* 🛡️ **Полная чистота:** Никаких рекламных баннеров, платных подписок, всплывающих окон и сторонних трекеров.

## ⚙️ Программная реализация и архитектура

### 1. Архитектурный подход (Clean / Hexagonal Architecture)
Проект написан на **чистом Python 3.11+ без сторонних runtime-фреймворков** и следует принципам **Hexagonal Architecture (Ports & Adapters)**, **GRASP** и **SOLID**:

```text
       [ CLI / Скрипты автоматизации / Контроллеры ]
                          │
                          ▼
 ┌──────────┐ ┌──────────┐ ┌─────────────┐ ┌──────────────┐
 │ parsing/ │ │ storage/ │ │ rendering/  │ │ translation/ │  ◀── Сменные адаптеры (Инфраструктура)
 └────┬─────┘ └────┬─────┘ └──────┬──────┘ └──────┬───────┘
      │            │              │               │
      └────────────┴──────┬───────┴───────────────┘
                          ▼
              ┌───────────────────────┐
              │        ports/         │  ◀── Контракты (typing.Protocol)
              └───────────┬───────────┘
                          ▼
              ┌───────────────────────┐
              │        domain/        │  ◀── Чистое ООП-ядро (0 зависимостей от I/O)
              └───────────────────────┘
```

* **Изолированное доменное ядро (`domain/`):** Сущности `Chapter`, `Block`, `StoryMetadata` и `ValidationReport` полностью отделены от файловой системы, сети и библиотек отображения. Бизнес-логика покрыта быстрыми юнит-тестами, исполняющимися в оперативной памяти.
* **Слабая связанность (Low Coupling):** Все адаптеры взаимодействуют с ядром через контракты (`typing.Protocol`), что позволяет легко заменять парсеры, хранилища или шаблонизаторы.

### 2. AST-парсер и структурная валидация
* **100% Round-Trip:** Парсер разбирает специализированную текстовую разметку глав в типизированное абстрактное синтаксическое дерево (AST) и гарантирует обратную сборку без потерь.
* **Инвариантная сигнатура (`structural_signature`):** Автоматический валидатор сопоставляет структуру перевода со структурой оригинала. Ни один системный блок, сценарий, авторский комментарий или сноска не могут пропасть или перемешаться.

### 3. Лингвистический контроль и терминология
* **Канонический глоссарий ([`glossary/orv_glossary.toml`](glossary/orv_glossary.toml)):** Содержит более 240 терминов, правил транслитерации и запрещенных контекстных вариантов.
* **Система Концевича:** Имена собственные и корейские онимы стандартизированы строго по научно признанной практической транскрипции (Ким Докча, Ю Джунхёк, Хан Суён, Ли Хакхён).
* **Морфологический контроль падежей:** Валидатор `GlossaryChecker` учитывает богатую падежную парадигму русского языка и вариативность `ё`/`е`, предотвращая появление несогласованных словоформ.
* **Семиотика веб-новеллы:** Сохранены все знаковые элементы: азиатские кавычки `「...」`, системные панели `<!>`, трансляции Внешних Богов `<#>【...】` и интерактивные сноски `<?>`.

### 4. AI-конвейер перевода (Protected Payload)
* **Изоляция разметки:** Специальный протокол выгрузки (`export-packet`) отделяет смысловой текст от технической верстки в изолированный JSON-контракт. Языковая модель работает исключительно с чистым текстом, что исключает порчу тегов и галлюцинации форматирования.
* **Скользящий контекст:** Чанкер разбивает длинные главы на фрагменты с сохранением смысловых границ и передает смежные фрагменты для целостности повествования.
* **Self-Healing Retries:** При обнаружении расхождений с глоссарием или нарушении сигнатуры пайплайн автоматически формирует скорректированный запрос.

### 5. Сборщик статики (SSG) и EPUB 3 Builder
* **Сайт:** Генерация быстрого статического сайта со встроенными метатегами, OpenGraph, PWA-манифестом, сервис-воркером и динамической фильтрацией глав.
* **EPUB 3:** Упаковка валидных книг с поддержкой спецификации `epub:type="endnotes"`, корректным деревом TOC и встроенными стилями системных окон.

### 6. Надежность и Serverless-развертывание
* **Строгая типизация:** 100% покрытие аннотациями типов, проверка `mypy --strict` (0 ошибок на 39 файлах).
* **Тестирование:** Комплект из 45+ тестов на `pytest` выполняется за **< 1 секунды**.
* **Zero-Cost Деплой:** Размещение в **Cloudflare Pages** обеспечивает глобальный CDN, поддержку HTTP/2, мгновенную загрузку и нулевые затраты на поддержку сервера ($0 / месяц).

## ⚡ Быстрый старт и команды

### 1. Тестирование и линтинг
```bash
# Запуск всех тестов
pytest

# Строгая проверка типов
mypy src/orv_ru

# Проверка стиля кода
ruff check src tests scripts
```

### 2. Сборка сайта и валидация глав
```bash
# Проверка глоссария и генерация статического сайта для всех историй
python3 scripts/verify_and_build.py --strict-glossary

# Результат сохраняется в директорию output/site/
```

### 3. Локальный предпросмотр
```bash
# Запуск локального сервера
PYTHONPATH=src python3 -m orv_ru serve --port 8080
# Доступно по адресу: http://localhost:8080
```

### 4. Публикация в Cloudflare Pages
```bash
# Деплой готовой сборки в облако (2–3 секунды)
npx wrangler pages deploy output/site --project-name=orv-ru
```

## 📁 Структура репозитория

```text
orv-ru/
├── config.toml                 # Конфигурация историй, путей и параметров ридера
├── glossary/
│   └── orv_glossary.toml       # Канонический словарь терминов (240+ записей)
├── data/
│   ├── chapters/               # Готовые переведенные главы на русском языке
│   │   └── cont/               # Главы побочной истории (553+)
│   └── work/                   # Рабочие пакеты перевода
├── src/orv_ru/
│   ├── domain/                 # Бизнес-сущности (главы, блоки, метаданные)
│   ├── ports/                  # Абстрактные интерфейсы (Protocol)
│   ├── parsing/                # AST-парсер разметки, сериализатор и валидатор
│   ├── storage/                # Репозиторий глав и файловые адаптеры
│   ├── rendering/              # Генераторы HTML-сайта и EPUB 3 книг
│   ├── translation/            # Поиск терминов, чанкер, пайплайн LLM
│   └── app/                    # Контроллеры приложения и CLI
├── web/                        # HTML-шаблоны и статика (CSS, JavaScript)
├── scripts/                    # Скрипты верификации и пакетной обработки
├── tests/                      # Набор юнит- и интеграционных тестов
└── output/                     # Артефакты сборки (исключены из Git)
```
