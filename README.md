## 💡 Что это за проект?

`orv-ru` — это современная веб-читалка, статический генератор сайтов (SSG), сборщик электронных книг EPUB 3 и конвейер контроля качества перевода культовой корейской веб-новеллы **«Точка зрения всеведущего читателя»** (*Omniscient Reader's Viewpoint, ORV*, автор Sing Shong) на русский язык.

На сайте доступны **3 раздела (истории)**:
1. **Основная история** (главы 1–551) — канонический сюжет о Ким Докче и сценариях выживания.
2. **Побочная история / Сиквел** (главы 553+) — продолжение новеллы о Ли Хакхёне и читателях в новой мировой линии.
3. **Ваншоты и бонусные главы** — спецвыпуски, дополняющие мир новеллы.

Проект работает как **быстрое легковесное веб-приложение (PWA)**, не требует серверов и баз данных, полностью автономен и открывается мгновенно на любых устройствах.

## 🎯 Зачем это создано?

Любительские переводы азиатских веб-новелл часто сталкиваются с тремя проблемами:
1. **Терминологический хаос:** В произведениях длиной более 1000 глав разные переводчики и нейросети называют одних и тех же героев, монстров, созвездия и навыки десятками разных вариантов.
2. **Потеря авторской верстки:** В ORV ключевую роль играет визуальный язык: голографические системные окна, особые скобки цитирования созвездий `「...」`, зловещие сообщения Внешних Богов и сноски. На обычных сайтах эта разметка теряется, превращаясь в нечитаемую кашу.
3. **Неудобные сайты с рекламой:** Большинство читалок перегружены всплывающими баннерами, долго загружаются, теряют прогресс чтения и не работают без интернета.

**Цель `orv-ru`** — предоставить эталонную читалку: чистую, без рекламы, с безупречным сохранением канонического оформления, строгим контролем терминов и возможностью комфортного чтения как онлайн, так и офлайн.

## 🎓 Для преподавателя и исследователя

### (Лингвистика, переводоведение, компьютерная филология и инженерия ПО)

Проект демонстрирует практическое применение **Computer-Assisted Translation (CAT)** и методов строгой программной верификации к художественному переводу:

1. **Систематизация терминологии и ономастики:**
   - Канонический глоссарий ([`glossary/orv_glossary.toml`](glossary/orv_glossary.toml)) формализует более **240 терминов** с контекстными правилами.
   - Имена собственные транскрибируются строго по практической системе Концевича для корейского языка (Ким Докча, Ю Джунхёк, Хан Суён, Ли Хакхён).
   - Сохранена и стандартизирована система корейских обращений и культурных маркеров (*хён, хённим, нуна, аджосси, сонбэ*).

2. **Детерминированный контроль падежей и морфологии:**
   - Компонент `GlossaryChecker` выполняет лемматизацию и поиск терминов с учетом богатой русской падежной парадигмы и вариативности букв `ё`/`е`. Это исключает «кальку» и несогласованные падежные окончания при машинно-ориентированном переводе.

3. **Инвариантность структуры (AST Validation):**
   - Текст новеллы формализован в виде грамматики (AST-дерево). Специальный метод `structural_signature()` проверяет перевод относительно оригинала: ни один системный блок, авторский комментарий, сценарий или сноска не могут быть пропущены или искажены моделью перевода.

4. **Сохранение семиотики текста:**
   - В переводе полностью сохранены авторские типографические приемы веб-новеллы:
     - `「...」` — канонические азиатские кавычки для мыслей и передачи реплик Созвездий;
     - `<!>` — полупрозрачные синие голографические панели системных уведомлений;
     - `<#>` / `【...】` — тяжелые сообщения Внешних Богов и трансляции Звездного Потока;
     - `<?>` — авторские сноски с моментальным переходом.

## 💼 Для работодателя и технического специалиста

### Архитектурный стек и инженерные решения

Проект спроектирован по канонам **Clean Architecture (Hexagonal / Ports & Adapters)** на **чистом Python 3.11+ без тяжелых внешних runtime-фреймворков**:

```text
       [ CLI / Automation Scripts / Controllers ]
                          │
                          ▼
 ┌──────────┐ ┌──────────┐ ┌─────────────┐ ┌──────────────┐
 │ parsing/ │ │ storage/ │ │ rendering/  │ │ translation/ │  ◀── Сменные адаптеры (Инфраструктура)
 └────┬─────┘ └────┬─────┘ └──────┬──────┘ └──────┬───────┘
      │            │              │               │
      └────────────┴──────┬───────┴───────────────┘
                          ▼
              ┌───────────────────────┐
              │        ports/         │  ◀── Строгие протоколы (typing.Protocol)
              └───────────┬───────────┘
                          ▼
              ┌───────────────────────┐
              │        domain/        │  ◀── Чистое ядро: 0 внешних I/O зависимостей
              └───────────────────────┘
```

#### Ключевые преимущества реализации:
* **Изолированный домен (`domain/`):** Доменные сущности (`Chapter`, `Block`, `StoryMetadata`, `ValidationReport`) не зависят от диска, сети, БД или форматов отображения. Это позволяет мгновенно тестировать бизнес-логику в памяти.
* **AST-парсер с гарантией 100% Round-Trip:** Парсер строит типизированное дерево блоков из специализированной `.txt`-разметки, умеет компилировать его обратно без потери данных и гарантирует сохранность разметки.
* **Собственный SSG и EPUB 3 Builder:** Генерация чистого, безопасного (авто-экранирование HTML) и легковесного статического сайта и валидных электронных книг со встроенными стилями и концевыми сносками (`epub:type="endnotes"`).
* **AI-конвейер с механизмом «Protected Payload»:**
  - При машинном переводе через LLM управляющие теги и структура извлекаются в защищенный контракт данных (JSON-пакет).
  - Модель переводит только чистый текст, что исключает галлюцинации и поломку технической верстки.
  - Скользящее контекстное окно (sliding window) обеспечивает связность повествования между блоками.
* **Качество кода и надежность:**
  - **100% Type Hints:** строгая проверка `mypy --strict` (0 ошибок на 39 модулях).
  - **Линтинг:** `ruff` с соблюдением стандартов PEP 8.
  - **Автотесты:** Комплект тестов на `pytest` выполняется за **< 1 секунды**.
* **Zero-Cost Serverless Hosting:**
  - Сборка разворачивается в **Cloudflare Pages** с глобальным edge-кэшированием, поддержкой HTTP/2, Brotli-сжатием и нулевой стоимостью содержания (0 руб. / $0 в месяц).

## ⚡ Быстрый старт и команды

### 1. Запуск тестов и линтеров
```bash
# Прогон юнит- и интеграционных тестов
pytest

# Строгая проверка типов
mypy src/orv_ru

# Линтер и форматирование
ruff check src tests scripts
```

### 2. Сборка сайта и проверка глоссария
```bash
# Валидация всех переведенных глав и генерация статического сайта
python3 scripts/verify_and_build.py --strict-glossary

# Результат сборки создается в директории output/site/
```

### 3. Локальный запуск читалки
```bash
# Встроенный HTTP-сервер для предварительного просмотра
PYTHONPATH=src python3 -m orv_ru serve --port 8080
# Откройте в браузере: http://localhost:8080
```

### 4. Деплой на Cloudflare Pages
```bash
# Публикация обновленного сайта в продакшн (занимает 2–3 секунды)
npx wrangler pages deploy output/site --project-name=orv-ru
```

## 📁 Структура репозитория

```text
orv-ru/
├── config.toml                 # Конфигурация историй, путей и параметров ридера
├── glossary/
│   └── orv_glossary.toml       # Канонический словарь терминов (240+ записей)
├── src/orv_ru/
│   ├── domain/                 # Бизнес-сущности (главы, блоки, метаданные)
│   ├── ports/                  # Абстрактные интерфейсы (Protocol)
│   ├── parsing/                # AST-парсер разметки, сериализатор и валидатор
│   ├── storage/                # Репозиторий глав и файловые адаптеры
│   ├── rendering/              # Генераторы HTML-сайта и EPUB 3 книг
│   ├── translation/            # Поиск терминов, чанкер, пайплайн LLM
│   └── app/                    # Контроллеры приложения и CLI
├── web/                        # Шаблоны (Jinja-подобные) и CSS/JS стили сайта
├── scripts/                    # Скрипты верификации и пакетной обработки
├── tests/                      # Полный набор юнит- и интеграционных тестов
└── output/                     # Артефакты сборки (исключены из Git)
```

## ⚖️ Чистая архитектура и Clean-Room

Репозиторий `orv-ru` спроектирован по методологии **Clean-Room**:
- В системе контроля версий Git хранится **исключительно оригинальный программный код, архитектура, шаблоны разметки, тесты и терминологический словарь**.
- Исходные тексты веб-новеллы, принадлежащие правообладателям, а также сгенерированные файлы сборки исключены через [`.gitignore`](.gitignore).
- Любой пользователь может клонировать данный репозиторий, запустить с собственными текстами глав и получить полностью рабочий автономный веб-сайт или EPUB-книгу.
